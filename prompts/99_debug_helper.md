# Debug helper (paste into opencode when something fails)

I'm a beginner. Something failed. Follow these rules:
1. Do NOT change code yet. First show me the exact command I ran and the exact error (I will paste it).
2. Explain in simple words what the error means.
3. List the top 3 likely causes, most likely first, and the quickest check for each.
4. Apply the smallest fix for the most likely cause, then re-run the same command and show the real output.
5. If it is still broken after 3 attempts, stop and give me a short summary I can paste to another assistant.
6. Never open .env or print keys. Never skip a failing test by deleting it.
