# Submission checklist
Items marked OFFICIAL come from the hackathon rules page as read on Oct 9, 2026. Re-read
https://nebiusglobalaihackathon.devpost.com/rules before submitting; rules can change.

## OFFICIAL requirements
- [ ] Deadline: Oct 30, 2026 10:00 am PDT (= 10:30 pm IST). Our own target: submit Oct 28.
- [ ] Track selected: Best Apps & Agents
- [ ] Working project that makes a runtime call to Nebius Token Factory (or runs on Nebius AI Cloud)
- [ ] Uses at least one NVIDIA open model (e.g. Nemotron)
- [ ] Hosted demo/test URL that judges can open without cost
- [ ] Public GitHub repo with a visible OSI-approved licence (MIT)
- [ ] README explains how Nemotron and Token Factory are used
- [ ] Demo video on YouTube, under 3 minutes, showing the working app
- [ ] Feedback on Nebius/NVIDIA tools (use FEEDBACK.md notes)
- [ ] Project stays available and free to test until judging ends (Dec 15)

## Our own quality checks (recommendations, not rules)
- [ ] `python -m pytest -q` passes
- [ ] No secrets in repo or git history; .env ignored
- [ ] Fresh-clone test works
- [ ] README numbers match results files
- [ ] Demo mode works with no API key
- [ ] Video contains no key, no private data
- [ ] Limits and honest claims stated in README and video
- [ ] Optional: Tavily bonus only if time remains (verify its requirements on the rules page first)
